# Agent Instructions

## Design

Before implementing or modifying UI:

1. Read `docs/DESIGN_GUIDELINES.md`.
2. Reuse existing components before creating new ones.
3. Follow existing spacing, typography, color, and interaction patterns.
4. Do not introduce new colors, font sizes, shadows, or border radii unless necessary.
5. Ensure responsive behavior and accessibility.
6. Match existing screens/components when there is ambiguity.

The design guidelines in `docs/DESIGN_GUIDELINES.md` are the source of truth.
